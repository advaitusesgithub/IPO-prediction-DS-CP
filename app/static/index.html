BEHIND THE ESTIMATES

A transparent view of the model.

Price estimates use a training-median premium over the announced price cap. A separate Random Forest estimates positive listing gain. Original results use a 0.5 threshold; the labeled 2026 audit uses a class-balanced model and a validation-selected 0.45 threshold.

How to read the labels

  • Held-out prediction: saved original evaluation result from an IPO not used for fitting.
  • Validation prediction: saved development result from an earlier-data model.
  • 2026 audit prediction: saved new-data test result from the documented refinement.
  • Training illustration: retrospective model output for a training IPO, not an independent forecast.

This version uses local historical data only. Live IPO research and web lookup are planned for a later version. Probabilities are uncalibrated; allotment and costs are not modeled.
